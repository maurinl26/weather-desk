`ne_110m_land.geojson` contains Natural Earth 1:110m land polygons. Natural Earth
data is public domain. The GeoJSON is sourced from the Natural Earth Vector
project's [`ne_110m_land.geojson`](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson).

The app uses these simplified polygons for land fills and coastline outlines so
all supported map projections have a local basemap without depending on tiles.
